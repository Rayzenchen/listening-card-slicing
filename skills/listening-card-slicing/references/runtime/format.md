# 运行时 · 清单、包与卡片字节契约

> 本文件只写**机器消费的字节规则**；怎么分组、怎么译、怎么断行见角色卡。
> 发行包不含 `tests/fixtures/`（真实转写夹具已剔除）；格式以本文件与 `scripts/` 的实现为准，示例只示格式，**不得照抄内容**。
> 任何字符级改动 = 接口变更：先改脚本与 fixtures，再同步本文件；不要只改文档。

## 1. `切分文本.txt`

一行 = 一个片段的纯口播文本，直接喂给切分程序；**第 n 行 = 清单第 n 行 = 第 n 个音频片段**。

| 规则 | 值 |
|---|---|
| 编码 | UTF-8，**无 BOM** |
| 行数 | 恰好 N 行（N = 清单行数） |
| 内容 | 一行 = 一个片段的纯口播文本 |
| 禁止 | 无 `M:` / `W:` 标记、无 `1、` 编号、无 `##` 标题、无行内换行 |
| 禁止 | 无空行、无行首/行尾空白（每行已 strip） |
| 结尾 | **恰好一个换行符**（最后一行之后一个 `\n`，不再多空行） |

- 只允许三类加工：**删不发音的排版标记**、**按规则分组**、**补句末句号**（只补排版标题生成的行）。
- 主体文本的句号来自用户原文，不补、不改、不删；音频里有原文没记录的语音 → 不写进切分文本、不补占位行、不编文本。

## 2. `切分清单.md`（5 列基线 → 6 列定稿）

### 2.1 5 列基线（E4 出台）

`<…>` 是占位符；**其余每个字符（含空格、全角标点、空行位置）都不可动**。

```markdown
# <stem> · 切分清单（含进卡组标记）

> 与 <stem>_切分文本.txt 逐行一一对应；行号 = 切出的音频编号（001、002…）。
> **进卡组＝是** 的 <K> 行 = 正文 <a> + 题目 <b>；**进卡组＝否** 的 <N-K> 行 = <报幕/指令/开场/结尾 里出现的那些>。
> 报幕（<报幕标签压缩串>）单独成行；“Questions X and Y are based on ...” 算指令，单独成行但不进卡组；每个 Question 单独成卡。

| 行 | 类型 | 进卡组 | 位置 | 原文（含说话人标识） |
|---|---|---|---|---|
| <NNN> | <类型> | <是/否> | <位置> | <原文> |

## 进卡组清单（<K> 行）

<压缩区间>

## 不进卡组清单（<N-K> 行）

<压缩区间>

<末尾固定句>
```

- 第 1 行：`# <stem> · 切分清单（含进卡组标记）`；`·` 是 U+00B7，两侧各一个半角空格。
- 第 2 行空行；第 3–5 行是**三行引用块**（不是两行）：对应关系 / 统计句 / 报幕与题目口径。
- 第 6 行空行；第 7 行 5 列表头；第 8 行 `|---|---|---|---|---|`（恰好 5 组 `---`，不写对齐冒号）。
- 表格行：`| <3 位行号> | <类型> | <是/否> | <位置> | <原文> |`；单元格之间 ` | `；行号 3 位补零；单元格内 `|` 转义成 `\|`。
- 类型只能是 `开场` / `报幕` / `指令` / `正文` / `题目` / `结尾`；`进卡组=是 ⟺ 类型 ∈ {正文, 题目}`。
- 表格之后：空行 → `## 进卡组清单（<K> 行）` → 空行 → 区间一行 → 空行 → `## 不进卡组清单（<N-K> 行）` → 空行 → 区间一行 → 空行 → 末尾固定句（文件最后一行）。
- `<末尾固定句>` 由 `scripts/common.py` 生成，整句是**冻结字节**（其中包含历史目录名，但**不再创建该目录**）；不要手写、不要手改，改它 = 接口变更。

### 2.2 统计句与报幕串

- 统计句：`> **进卡组＝是** 的 <K> 行 = 正文 <a> + 题目 <b>；**进卡组＝否** 的 <N-K> 行 = <否类串>。`
  - `K = a + b`；`N-K` = 四类否行之和；**数字必须被表格重算出来**，不许手填。
  - 是侧永远写两个数（即使为 0）；否类顺序固定 `报幕/指令/开场/结尾`，只列计数 > 0 的类型，用半角 `/` 连接。
- 报幕串：按「前缀 + 尾部记号」拆，同前缀归一族；族按首次出现排序，族内记号用 `/`，族间用 `、`（U+3001）。例：`Section A/B/C、News Report 1/2/3`。
- 引用块的引号是全角 `“ ”`；`...` 是三个半角点，别换成 `…`。

### 2.3 位置列（人读标签，不是键）

| 来路 | 写法 |
|---|---|
| 开场 | `开场` |
| Section 报幕 / Directions | `Section X`（两者同值） |
| 篇目报幕 | `Section X / <篇目标签>` |
| 正文 | `Section X / <篇目标签> (Qa-b)` |
| Questions 指令 | `Section X / Qa-b` |
| 题目 | `Section X / QN` |
| 结尾 | `录音结尾` |

- 写法全部来自 contract v1 标签：Section 报幕来自 `## Section X`，篇目来自 `### 篇目 [Qx-y]`，Q 范围来自 `body.q_range`（见 [transcript-contract.md](transcript-contract.md)）。
- 分隔符 ` / `（半角斜杠，两侧各一个空格）；Q 范围用**半角 `-`**（`Q1-2`），与区间压缩的 U+2013 `–` 不同。
- 位置**不是唯一键**：Section 报幕与 Directions 同值；同一篇目的多行正文共用同一位置。分组用「类型 + 行号连续」，不要 `GROUP BY 位置`。

### 2.4 区间压缩

- 行号 3 位补零、升序、只列该组；连续 ≥ 2 行 → `首–末`（U+2013）；单独一行 → 3 位数字；段间用 `、`（U+3001），不留空格。
- 全组为空 → 只留标题与一行 `（无）`。

### 2.5 6 列定稿（E5）

- E5 只在 5 列右侧**追加**第 6 列 `译文`：表头变成 `| 行 | 类型 | 进卡组 | 位置 | 原文（含说话人标识） | 译文 |`，分隔行多一组 `---`；表头整体下移一行。
- 三行引用块之后**加一行** `> **译文**列…` 说明；前 5 列、两段区间、末尾固定句逐字不变。
- keep 行：译文一格内用 `<br>` 连接多个中文句；否行：两个空格（空单元格）。
- E5 定稿后第 6 列也冻结；`approve.json.manifest_sha256` 绑整份 6 列清单，`approve.json.rows[{n,sha256}]` 绑每一行（`gate e9` 重算）。

## 3. 「原文」列 ↔ 切分文本（唯一允许的换算）

- 清单原文列：对每个原子，`speaker != null` 时输出 `**M:** ` / `**W:** ` 再跟原子文本，原子间一个半角空格；说话人标记**逐原子重复**（独白无标记）。
- 切分文本行：把清单原文列里的所有 `**M:** ` / `**W:** ` 删掉，连续空白压成一个半角空格并 strip。
- **不可反推**：切分文本没有说话人信息，清单是源、切分文本是投影；`assemble.py` 必须先有 `segments.json` 再同时投影两个文件。

## 4. 编号、包与冻结

| 对象 | 规则 |
|---|---|
| 包目录 | `产出区/<stem>_音频切分（进牌组）/`（全角括号、下划线半角） |
| 片段文件 | `<NNN>.wav`，NNN = 清单行号（3 位补零） |
| 包内清单 | `<stem>_切分清单.md`（与 `$RUN` 副本同 sha） |
| 评审期清单 | `产出区/<stem>_切分清单.md`（E8 收尾由 cleanup 删） |

- **编号不是 keep 行的连续序号**：否行留空号，包内文件名有断号是正常的；文件名集合 = keep 行列号集合。
- **包内只有清单 + wav**：无 JSON/CSV/txt 索引、无子目录、无 ZIP 副本、无 `.DS_Store`；wav 数 = keep 行数、每个 wav > 0.2 s。
- **sha 绑定**：`segments.manifest_sha256`、`doc.json.manifest_sha256`、包内清单前 5 列与 `manifest-5col.md` 一致；E5 的 6 列 sha 由 `approve.json` 绑定。
- **扩展兼容**：包内清单在 `manifest-5col.md` 右侧多第 6 列/说明行、且前 5 列、表头前 5 格、区间行、固定句逐字不变 → `gate e7`/`e8` 记 `WARN pack_manifest_extended`，**不 FAIL**；其它任何差异 FAIL。
- **卡住不要手改**：清单/切分文本是证据链，手改一处就对不上；回上游重跑（改译文走 `translate_apply.py --review`）。

## 5. 卡片字节（E9，`cards_apply.py` 渲染）

```text
[T#!!fff895#{title}]
[T#!275bd1#先听听看是什么意思]
---
[Audio#A,ID/{{AUDIO_ID}}#]

[T#!275bd1#尽可能复述一下意思，完成后再往下点]
---
{zh lines}
---
[T#!275bd1,!!#最后对着原文听一遍，对一下单词和发音：]

{en lines}
---
[Audio#A,ID/{{AUDIO_ID}}#]
```

| 规则 | 值 |
|---|---|
| 编码 / 换行 | UTF-8 无 BOM；只用 `\n` |
| `---` | 恰好 4 条，每条恰好 3 个半角连字符 |
| 空行 | 恰好 2 个（Audio 正面之后、英文提示之后） |
| 首字符 / 末字符 | `[` / `]`；**没有尾随换行** |
| 标题 | `【Y<YY>M<MM>-\[<卷号罗马>\]_<家族>】`；标题内 `[` `]` 带反斜杠转义，外层 `【】` 不转义 |
| 音频 | 正反两面两处 `{{AUDIO_ID}}` 必须是**同一个** `mkjf_` id；替换后 `content.count("mkjf_") == 2` |
| 中文块 | 一句一行，来自 `translations.json`；对话只在换人处 `M: ` / `W: ` |
| 英文块 | 一句起行；分句 `- `，嵌套 `-- `（只一层）；断点前一行行尾恰好 1 个空格 |
| 说话人 | 只在句子行首、只在换人处；由脚本按 `speakers` 加，排版员不写 |
| 模板身份 | `content_template` 存 `{{AUDIO_ID}}` 占位；`cards.json` 记 `content_sha256`；push 时替换真实 id |

- 标题 / 家族：正文 `NR<篇>-<序>` / `Cs<篇>-<序>` / `Pa<篇>-<序>`，题目 `Q<两位题号>`；章节名 `精听：<YY>年<MM>月-卷<N>`。
- 卡片正文与清单「原文」列的比较：双方都剥 `- `/`-- ` 前缀、剥 `M:`/`W:`、压空白后逐字比；**不改字**是硬检查。
- 逐字模板以 `scripts/cards_apply.py` / `common.py` 的实现为准；运行时不照抄示例内容。
