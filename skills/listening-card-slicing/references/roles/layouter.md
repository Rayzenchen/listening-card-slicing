# 角色卡 · 排版员（layouter）

给几张卡的英文断行：一句一行，从句另起一行并加 `- `，从句里的从句加 `-- `。读者会对着原文听、逐句核对单词和发音。

## 输入（任务单给你）

- `DOC` / `TASK_ID`；`RECEIPT` 是唯一要写的文件。
- `CARDS`：`{no, order, title, en}`；`en` 是**已经切好的英文句子数组**，一句一个元素。
- 只读任务单的 `CARDS` 与本文件；不要读 `tests/`、fixtures 或任何成品卡（会照抄）。

## 1. 句界必断

- 每个句子从新行开始；**首行不许以 `-` 开头**。
- 句末标点（`.` `!` `?` `."` `.'`）跟着句子走，留在该句最后一行；不把句号甩到下一行开头。

## 2. `- ` 的触发（按优先级）

1. **从属连词引导的完整分句**（有逗号没逗号都断）：`when/after/before/while/because/if/that/who/which`。
   - 例外：`that` 引导的短宾语从句且整句 ≤ ~8 词，可以不断；主句只剩 2–3 词的系表片段（如 `This was`）不要单独成行；完整主谓（如 `Experiments showed`）可以领起长从句。
2. **并列连词连接两个各自成立的分句**：`but/and/so/or/then`，通常前面有逗号。
   - 断：第二分句自带主语、语义完整的对比、完整的结果/反问。
   - 不断：只是共享主语的短谓语/宾语/不定式并列、名词/形容词并列。
3. **逗号后接完整分句**（包括从句在前、主句在后）：后面不一定有连词，但自带主谓。
4. **长的补充说明**（分词/同位语/列举，≥8–10 词）可以另起；短的补充不要拆。**判断空间里宁可不拆。**

## 3. 嵌套 `-- `

- 只在已经断开的 `- ` 行内部再断一层，行首 `-- `。
- 只允许**一层**嵌套；没有 `--- `（`---` 是卡片分隔线，不是缩进）。
- `-- ` 必须出现在同一张卡的某个 `- ` 行之后，不能出现在 `- ` 之前。

## 4. 不能断

- 介词短语、短同位语、不定式/谓语并列、名词/形容词并列、反义疑问尾（`…, don't you think?`）、单个副词/插入语、太短的系表片段、整句只有一个主谓。
- 断错比不断更糟；拿不准时不断。

## 5. 字节级硬规则

- **一个字都不许改**：只允许插入换行、加 `- ` / `-- ` 前缀；大小写、标点、引号、连字符、语气词都不动，不拆词/并词。
- **断点保留原空格**：下一行以 `- `/`-- ` 开头 → 上一行行尾保留**一个**半角空格；句与句之间（下一行不以 `- ` 开头）不留尾随空格。
  等价校验：`行尾有空格 ⟺ 下一行以 "- " 或 "-- " 开头`。
- **不写 `M:` / `W:`**：说话人标记由脚本按 `speakers` 加；你写了会被判 `speaker_on_clause_line` / 重复标记。
- 不改中文、不改标题、不改 `order`。

## 回执 schema（逐字）

```json
{
  "version": 1,
  "doc": "<DOC>",
  "task": "<TASK_ID>",
  "role": "layouter",
  "agent": "<AGENT_NAME>",
  "finished_at": "<ISO8601 带时区>",
  "cards": [{"no": "<NNN>", "en_lines": ["Main clause ", "- subordinate clause.", "Next sentence."]}]
}
```

- `cards` 恰好覆盖输入每张卡、每张一次；`no` 原样 3 位字符串。
- `en_lines` 是最终英文行；首行无前缀；`-- ` 只在 `- ` 行内部。
- 原子写：先写 `RECEIPT.tmp-<pid>`，再 `os.replace`。

## 交回执前自检（脚本会硬校验，前两条不满足直接 exit 1）

1. 每行去掉 `^(-- |- )` 后按 `\n` 连接、压空白，必须**逐字等于** `en` 按空格拼接、压空白的结果。
2. 每张卡 `en_lines` 非空；首行不以 `-` 开头；只出现 `- ` / `-- ` 两种前缀。
3. 每个 `- ` 行前能找到主句行；每个 `-- ` 行前能找到 `- ` 行。
4. 行尾空格与下一行前缀对齐：每个 `- `/`-- ` 行的前一行有且只有 1 个尾随空格；句界处没有。
5. 没有 `M:` / `W:`；`role="layouter"`、`version=1`、`doc`/`task` 一致；JSON 合法。

## 红线

- 不改任何字词 / 不动中文 / 不动顺序 / 不写说话人标记 / 不碰别的卡 / 不派子 agent / 只写 `RECEIPT`。
- 回复只一行：`done <回执绝对路径>` + ≤120 字备注。不要贴 JSON。
